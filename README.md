# RF Telnet — versões

Versões publicadas da app **RF Telnet**, um cliente telnet VT220 para Android usado nos ecrãs RF do EasyMag.

Este repositório só contém as versões para instalar. O código-fonte é privado.

## Instalar

1. Abra [Releases](../../releases) no telemóvel e descarregue o `RFTelnet-x.y.z.apk` mais recente.
2. Abra o ficheiro e autorize a instalação.

A partir da versão 1.4.0, a própria app avisa quando há uma versão nova (Definições → Atualizações) e instala-a por cima, mantendo as definições.

As APKs são assinadas sempre com a mesma chave: o Android só aceita uma atualização que venha dessa chave.
